# waterdrone-software

Software for the UKRAINIX WATERDRONE project.

## Layout

| Folder | Purpose |
|---|---|
| `analysis-app/` | The software analysis app: source code, scripts, configuration, app-specific docs. |
| `samples/` | Test samples for the analysis app, plus the scripts that analyze, remake and generate them. |

Additional apps (for example, a waterdrone configurator) will be added later as separate top-level folders next to `analysis-app/`.
